## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
เขียนโปรแกรมตรวจสอบกระเบื้องว่าแต่ละแผ่นมีจุดเสียง
ไม่สมบูรณ์กี่จุดแล้วหาจำนวนแผ่นเสียและจำนวนจุดเสียของแต่ละแถวและคอลัมแล้วคำนวณค่าปรับทั้งหมด
Input
รับขนาดตาราง N และค่าปรับต่อจุด P
รับจำนวนจุดเสียของกระเบื้องแต่ละแผ่น
Output
แสดงข้อมูลกระเบื้องแต่ละแถว พร้อมจำนวนแผ่นเสียและจุดเสีย
แสดงจำนวนแผ่นเสียและจุดเสียของแต่ละคอลัมน์
แสดงจำนวนแผ่นเสียทั้งหมด จุดเสียทั้งหมด และค่าปรับรวมทศนิยม 2 ตำแหน่ง
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: 
รับข้อมูลกระเบื้อง
n, penalty = input().split()
n = int(n)
penalty = float(penalty)

tiles = []

for _ in range(n):
    row = list(map(int, input().split()))
    tiles.append(row)

รับขนาดตาราง n และค่าปรับ penalty จากนั้นรับข้อมูลกระเบื้องแต่ละแถวเก็บไว้ใน tiles ซึ่งเป็นตาราง 2 มิติ

Step 2:
คำนวณจำนวนแผ่นเสียและจุดเสีย
col_bad_tiles = [0] * n
col_bad_points = [0] * n

for row in tiles:
    bad_tiles = 0
    bad_points = 0

    for j in range(n):
        if row[j] > 0:
            bad_tiles += 1
            col_bad_tiles[j] += 1

        bad_points += row[j]
        col_bad_points[j] += row[j]

    print(*row, bad_tiles, bad_points)
วนดูข้อมูลทีละแถว โดยถ้าค่ามากกว่า 0 ให้นับเป็นกระเบื้องเสีย 1 แผ่น ส่วน bad_points จะรวมจำนวนจุดเสียทั้งหมดในแถวนั้น และเก็บผลรวมของแต่ละคอลัมน์ไว้ด้วยcol_bad_tiles = จำนวนแผ่นเสียในแต่ละคอลัมน์
col_bad_points = จำนวนจุดเสียในแต่ละคอลัมน์
print(*row, ...) ใช้แสดงข้อมูลโดยเว้นวรรคระหว่างตัวเลข

Step 3: 
สรุปผลและคำนวณค่าปรับ
total_bad_tiles = sum(col_bad_tiles)total_bad_points = sum(col_bad_points)print(*col_bad_tiles)print(*col_bad_points)print(total_bad_tiles, total_bad_points,      f"{total_bad_points * penalty:.2f}")

นำผลรวมของแต่ละคอลัมน์มาบวกกันเพื่อหาจำนวนแผ่นเสียและจุดเสียทั้งหมด จากนั้นคูณจำนวนจุดเสียทั้งหมดด้วยค่าปรับต่อจุด ใช้:.2f ทำให้ค่าปเป็ฯทศนิยม 2 ตำแหน่ง
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
เหมือนกันกับวิธีคิดแรก เนื่องจากส่งแล้วผ่าน
```

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

- คัดลอก code ของผู้อื่น

- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
