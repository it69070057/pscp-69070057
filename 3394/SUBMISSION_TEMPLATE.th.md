## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ต้องการหาว่ามีนักเรียนกี่คนที่ได้รับข้อความต่อจากนักเรียนหมายเลข S โดยแต่ละคนจะส่งต่อข้อความไปยังนักเรียนอีกคนตามหมายเลขที่กำหนด ถ้าส่งไปยัง 0 แปลว่าหยุดส่ง และถ้าเจอคนที่เคยได้รับข้อความแล้วก็หยุดนับเพื่อไม่ให้วนซ้ำ
Input
บรรทัดแรก รับจำนวนนักเรียน N และหมายเลขนักเรียนเริ่มต้น S จากนั้นรับหมายเลขนักเรียนที่แต่ละคนจะส่งข้อความต่อไปให้ โดย 0 หมายถึงไม่ส่งต่อ
Output
แสดงจำนวนคนที่ได้รับข้อความทั้งหมด รวมคนเริ่มต้นด้วย

หมายเลขนักเรียนอยู่ระหว่าง 1 ถึง N หรือเป็น 0 และการส่งต่ออาจวนกลับมาหาคนเดิมได้ จึงใช้ set เก็บคนที่เคยนับแล้วเพื่อป้องกันการนับซ้ำ
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: 
รับข้อมูลนักเรียน
n, s = map(int, input().split())

forward = []

for _ in range(n):
    forward.append(int(input()))



รับจำนวนนักเรียน n และหมายเลขเริ่มต้น s จากนั้นเก็บหมายเลขนักเรียนที่แต่ละคนจะส่งข้อความต่อไปให้ไว้ใน forward

Step 2:
วนตามการส่งข้อความ
visited = set()
current = s

while current and current not in visited:
    visited.add(current)
    current = forward[current - 1]

สร้าง set ชื่อ visited เพื่อเก็บคนที่ได้รับข้อความแล้ว จากนั้นวนตามหมายเลขคนที่ส่งต่อไปเรื่อย ๆ จนกว่าจะเจอ 0 หรือเจอคนที่เคยได้รับข้อความแล้ว
current คือหมายเลขนักเรียนคนปัจจุบัน
current - 1 เพราะ index ของ list เริ่มที่ 0 แต่หมายเลขนักเรียนเริ่มที่ 1

Step 3: 
แสดงจำนวนคนทั้งหมด
print(len(visited))

ใช้ len(visited) นับจำนวนนักเรียนที่ได้รับข้อความ โดยนับรวมคนเริ่มต้นด้วย และไม่มีการนับคนเดิมซ้ำ แม้การส่งข้อความจะวนกลับไปหาคนเดิมก็ตาม
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
เหมือนกันกับวิธีคิดแรก เนื่องจากส่งแล้วผ่าน
```

- อธิบายความหมายของโจทย์

- คุยเรื่อง test cases

- คัดลอก code ของผู้อื่น
