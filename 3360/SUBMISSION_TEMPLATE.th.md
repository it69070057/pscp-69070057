## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ต้องการตัดขนมปังตามตำแหน่งที่กำหนดทั้งแนวกว้างและแนวยาว แล้วหาพื้นที่ของขนมปังแต่ละชิ้น จากนั้นแสดงพื้นที่ของ 2 ชิ้นที่มีขนาดใหญ่ที่สุด เรียงจากมากไปน้อย
Input
บรรทัดแรก รับความกว้าง w ความสูง h และจำนวนรอยตัดในแต่ละแนว จากนั้นรับตำแหน่งรอยตัดแนวกว้างและแนวยาวตามลำดับ
Output
แสดงพื้นที่ของขนมปัง 2 ชิ้นที่ใหญ่ที่สุด โดยเรียงจากมากไปน้อย

ต้องนำขอบเริ่มต้น 0 และขอบสุดท้าย w หรือ h มารวมด้วย เพื่อคำนวณขนาดแต่ละชิ้นจากระยะห่างระหว่างรอยตัด แล้วนำความกว้างคูณความสูงเพื่อหาพื้นที่ของแต่ละชิ้น
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: 
รับข้อมูลและเพิ่มขอบขนมปัง
w, h, _, _ = map(int, input().split())
x = list(map(int, input().split()))
y = list(map(int, input().split()))

x = [0] + x + [w]
y = [0] + y + [h]

รับความกว้าง w ความสูง h และตำแหน่งรอยตัดทั้งสองแนว จากนั้นเพิ่ม 0 และขอบสุดท้ายเข้าไปใน list เพื่อให้คำนวณขนาดขนมปังทุกชิ้นได้ครบ

Step 2:
หาความกว้าง ความสูง และพื้นที่แต่ละชิ้น
widths = []
heights = []

for i in range(1, len(x)):
    widths.append(x[i] - x[i - 1])

for i in range(1, len(y)):
    heights.append(y[i] - y[i - 1])

areas = []

for width in widths:
    for height in heights:
        areas.append(width * height)

นำตำแหน่งรอยตัดที่อยู่ติดกันมาลบกัน เพื่อหาความกว้างและความสูงของแต่ละชิ้น จากนั้นนำความกว้างทุกค่าคูณกับความสูงทุกค่า เพื่อหาพื้นที่ของขนมปังแต่ละชิ้น

Step 3: 
เรียงพื้นที่และแสดง 2 ชิ้นที่ใหญ่ที่สุด
areas.sort(reverse=True)

print(areas[0], areas[1])

ใช้ sort(reverse=True) เรียงพื้นที่จากมากไปน้อย แล้วแสดงสมาชิก 2 ตัวแรก ซึ่งเป็นพื้นที่ของขนมปัง 2 ชิ้นที่ใหญ่ที่สุด
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
เหมือนกันกับวิธีคิดแรก เนื่องจากส่งแล้วผ่าน
```

- อธิบายความหมายของโจทย์

- คุยเรื่อง test cases

- คัดลอก code ของผู้อื่น

- ใช้ OJ submission ของผู้อื่น
